# 겸재를 가까이 보다
대구간송미술관에서 발견한 작은 사람과 생명들

- 전시: 《겸재 정선 - 조선의 눈으로 조선을 그리다》 (겸재 정선 탄신 350주년 기념 특별전)
- 장소: 대구간송미술관 (대구 수성구 미술관로 70)
- 기간: 2026.09.16 – 2026.12.27
- 기록: 2026년 10월 관람 · 촬영 25장 (업로드 26장 중 중복 1장 제외)
- 구성: 7개 장, 25장면 (사람 10 · 배 3 · 동물 3 · 곤충 2 · 나무와 집 3 · 붓 3 · 전체 1)

## 사용법
- `index.html`을 열면 아카이브가 열립니다 (GitHub Pages 배포 가능).
- 작품명이 확인되면 `data/works.js`에서 해당 장면의 `work`와 `conf`만 수정합니다.
- 메모·확인한 작품명은 브라우저에 저장되며, '기록 노트 > 기록 복사하기'로 옮길 수 있습니다.

## 확신도
- ok(확인): 명제·관서·도록 등으로 작품 확인
- likely(유력): 도상과 알려진 작품 구성이 상당히 일치
- unknown(미확인): 사진만으로 특정 작품과 연결하기 어려움

## 보관 형태
- 이 폴더의 `index.html`은 외부 글꼴을 불러오지 않는 **오프라인 보관본**입니다. 인터넷 없이도 그대로 열립니다(시스템 명조 글꼴 사용).
- claude.ai에 게시한 웹 아카이브는 사진을 파일 안에 담은 단일 파일(약 5.7MB)이라 휴대폰 데이터로 처음 열 때 느릴 수 있습니다.

## 확인 정보 기준
- 〈금강내산〉: 정선, 《해악전신첩》(1747, 보물) 수록, 비단에 수묵담채, 약 32.6×49.6cm, 간송미술문화재단. 화면의 '金剛內山' 화제와 '겸재' 관서·인장.
- 작품명이 미확인인 장면에서는 작가를 주어로 쓰지 않습니다.

## 공개 범위
이 아카이브는 개인 관람 기록용입니다. 미술관에서는 일반적으로 플래시·삼각대·셀카봉과 상업적 용도의 촬영을 제한하며,
대구간송미술관의 최신 이용정책은 직접 확인하지 못했습니다. 온라인 공개·재사용 전 미술관 안내를 확인하고 출처를 표기하세요.
